# 云备份（Cloudflare R2）· 已配置完成

> **2026-07-26 更新：这一页你不需要做任何事了。** Claude 已在你的 Cloudflare 账号里建好存储桶和专用密钥，并把配置直接打进软件（`src-tauri/resources/r2.config.json`，打包时自动带上）。

## 现在的状态

- 存储桶：`banshan-backup`（私有，未开公共访问）
- 专用密钥：`banshan-workbench`（只对这一个桶有读写权限，不能动你账号里的其他东西，永久有效）
- 软件读取顺序：系统环境变量（如果你手动设过）→ 软件自带的 `r2.config.json`
- 登录账号表与业务备份都走这个桶

## 多台电脑怎么办

**直接装同一个安装包就行。** 配置在安装包里，装好即连通，什么都不用填。

## 想换桶 / 换密钥 / 出问题了

- 跟 Claude 说一声即可，Claude 可以在你的浏览器里重建并更新配置；
- 或者手动改 `src-tauri\resources\r2.config.json` 里的值后重新打包。
- 如果怀疑密钥泄露：去 Cloudflare → R2 → 管理 API 令牌，把 `banshan-workbench` 删掉重建，然后让 Claude 更新配置。

## 安全提醒

- 这份密钥只对 `banshan-backup` 一个桶有权限，拿到它动不了你 Cloudflare 里的其他资源；
- 但安装包里带着它，**不要把安装包发给公司以外的人**；
- 费用：R2 免费额度 10GB 存储，账号表只有几 KB，业务备份正常使用远用不满；用量在 Cloudflare 的 R2 页面随时可查。

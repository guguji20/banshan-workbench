## 一、登录与账号（对应"管理员可随时添加/删除账号"）

**用法（傻瓜版）**：

1. 装好后第一次打开 → 创建管理员账号（用户名 + 密码）→ 直接进入软件
2. 管理员开账号：设置 → **账号与用户** → 输入用户名/初始密码/角色 → 添加账号
3. 删人：同一页面点删除 → 再点一次确认 → 该账号在**所有电脑**上失效（需联网同步）
4. 每个人可以自己改密码；管理员可以给任何人重置密码；右上角设置里可退出登录

**多台电脑账号通用的原理**：账号表（密码加密后）存到你的 Cloudflare R2（就是云备份那个桶，路径 `bsaigc-backup/v1/registry/auth-users.json`），每台电脑登录时自动拉最新账号表；断网时用最近一次缓存照常登录，不耽误干活。**前提**：每台电脑先按 `docs/云备份R2配置指南.md` 跑一次「配置云备份.bat」。没配 R2 时账号只在本机生效（登录页会写明）。

**安全口径（说实话）**：密码用 PBKDF2-HMAC-SHA256 加密存储（6 万轮，逐用户随机盐，不存明文，附标准测试向量的单元测试）；这挡的是"没账号打不开软件、离职秒删号"，挡不住拿到电脑文件的人直接读数据库——办公室管理够用，硬加密是另一档工程。

**兼容性**：老数据完全不受影响（只是新增两张表）；万一登录出问题，删掉数据库里 `app_users` 表即可回到无登录状态（应急后门，写在这里备查）。

## 二、第一批交互补全（对应"界面缺交互"）

## 四、本机验收路径（在 1.2.3 基础上新增）

1. `一键验收.bat` 全绿（首次会编译较久）
2. `启动开发版.bat` → 应出现登录页 → 创建管理员 → 进入
3. 设置 → 账号与用户 → 添加一个员工账号 → 退出登录 → 用员工账号登录（应看不到用户管理）→ 再退回管理员删除该员工
4. 配好 R2 的前提下：第二台电脑（或删库重装）登录页应能直接用第一台创建的账号登录
5. 工作台对话条目悬停 → 「…」→ 归档/删除；输入框回形针上传一个文件

## 五、已知边界

- 账号同步为"最后写入生效"（小团队够用）；两台电脑同一秒各改账号表，后写的覆盖先写的
- 登录不加密业务数据（见上"安全口径"）
- 修改密码后其他电脑要联网同步一次才认新密码

## 六（补充）、在线更新与发布链路（本轮追加）

- **同事升级**：设置 → 更新与关于 → 手动检查 → 出现「下载新版本」按钮 → 点击在浏览器下载安装包 → 双击安装即完成升级（数据不受影响）。
- **老板发版**：改好版本号后双击「发布新版.bat」——自动打包 → 上传到云端发布桶（banshan-releases，公开只读）→ 更新版本信息。同事那边点检查更新就能看到。
- 发布桶与数据桶完全分开：数据桶（banshan-backup）私有存账号表与备份；发布桶只放安装包与版本号，公开可下载。
- 检查更新只在点「手动检查」时联网（10 秒超时），平时不联网。
- 新装电脑：直接把发布桶里最新的 setup.exe 发给对方安装即可（地址见发布脚本输出）。

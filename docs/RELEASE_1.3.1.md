# 半山商务工作台 1.3.1 更新说明

- 版本：`1.3.1`
- 日期：`2026-07-28`
- 定位：当前成果保全版，修复编译问题并补齐今天完成的桌面交互
- 发布状态：本地安装验收通过，待 GitHub 与 R2 归档

## 本版内容

1. 对话输入框支持随内容自动增高，附件以卡片方式展示。
2. 支持从文件选择器、拖拽和剪贴板添加文件或截图。
3. 支持绑定本地文件夹工作区，并选择访问权限。
4. 对话支持重命名、置顶、归档和删除。
5. 模型选择移到输入区右侧，账号与设置入口统一放到左下角。
6. 登录支持记住账号和密码、密码显示与隐藏、退出登录。
7. 新增本机工作区和附件上下文协议，完善桌面 Host 调用。
8. 修复 Rust 桌面端编译错误，并补齐新版 Clippy 兼容性。
9. R2 运行配置改为本地或 CI 注入，源码仓库只保留无密钥示例。
10. 存档业务版 1.0 总计划，本版不提前混入后续业务重构。

## 验收标准

- `pnpm verify` 全部通过。
- Windows NSIS 安装包可以静默安装、连续启动并正常退出。
- 内部安装包包含现有 AI 与 R2 运行配置，但源码归档不得包含明文密钥。
- 安装包、源码快照、发布说明和 SHA-256 清单上传 R2 后重新下载校验一致。

## 安全说明

`src-tauri/resources/r2.config.json` 只用于本地内部构建，已从 Git 跟踪中移除。公开仓库历史中曾经提交过旧 R2 凭据，发布后必须轮换该组旧凭据；本次不擅自重写 Git 历史或改动云端密钥。

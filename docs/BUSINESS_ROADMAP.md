# 半山商务工作台 · 商务板块方案 V3

- 日期：2026-07-26
- 范围依据：访谈纪要（只取商务部分）+ 三轮范围确认
- 基线：1.2.2（商务闭环 + 新版壳层）

## 零、已拍板的范围

**不做**：案例库找片（暂做不到，忽略）；销帮帮/飞书打通；分秒帧反馈汇总；审片/成片审核机制。

**聚焦**：**洽谈 → 报价 → 审核 → 自动化 → 模板化**，外加一条新主线：**商务智能体**（类 frakio/Codex 的多角色 AI 工作台，吸纳办公技能，专治验收/合同这类重复文书）。

## 一、总体思路

产品分两层，各管一件事：

- **闭环层（已有，继续夯实）**：客户 → 需求 → 报价 → 合同 → 请款 → 验收 → 回款 → 归档。特点是"结构化、留痕、不可乱"——单据快照、状态机、台账。
- **智能体层（本方案新增）**：一组懂商务的 AI 角色，坐在闭环上面干"重复的文字活"——起草、整理、转译、追问。特点是"快、可改、永远只出草稿"，正式生效必须回到闭环层走单据流程。

这样既拿到 AI 的省力，又不破坏台账的严谨。

## 二、商务智能体（新主线，类 frakio 多角色工作台）

### 2.1 形态

工作台对话区升级为**智能体团队**：左侧选角色，每个角色有自己的名字、职责说明、技能卡（一键任务按钮）；对话仍走现有 Codex 链路，但每个角色自动带两样东西：

1. **角色预设**：这个角色的职责、口吻、输出格式约定；
2. **项目上下文**：当前项目的真实数据自动注入——合同金额、付款节点、里程碑与交付状态、审查发现、需求 Brief——不用手工复制粘贴。

### 2.2 V1 角色与技能（全部商务向）

| 智能体 | 治什么重复活 | 技能卡（一键生成） |
| --- | --- | --- |
| **洽谈助手** | 需求反复确认、模糊反馈 | ① 根据已答问题生成追问清单；② 把零散沟通记录整理成 Brief 草稿；③ 模糊反馈追问话术（"高级"是指材质/构图/节奏/色彩？） |
| **报价助手** | 报价反复搭、行项措辞 | ① 按 Brief 起草报价行项建议（配合报价模板）；② 行项服务说明润色成客户可读版本；③ 报价说明函 |
| **合同审核助手** | 审查结论的二次加工 | ① 把审查发现整理成给客户的修改意见函；② 人工决策汇总成审查纪要；③ 逐条用大白话解释风险条款 |
| **验收请款助手** | **验收单/请款单重复文书（你点名的）** | ① 根据里程碑+交付版本起草验收单交付摘要；② 引用合同付款条款+节点金额起草请款说明；③ 回款催收提醒话术（按账期口吻分级） |

### 2.3 边界（重要）

- 智能体**只出草稿**：验收摘要、请款说明生成后，粘贴/带入到对应单据字段，走正常"创建→批准→生效"流程，快照照冻结、台账照记账。
- AI 不落章、不改台账、不直接改单据状态——与合同审查"AI 初筛 + 人工确认"同一规范。

### 2.4 实施分两步

- **V1（本轮就做，纯前端）**：角色预设 + 上下文注入 + 技能卡，走现有会话链路。云端可全量验证，不动 Rust。
- **V2（后续立项）**：多智能体协作（一个任务多个角色接力/并行）、智能体直接产出单据草稿对象（预填到表单）、自定义角色与技能编辑器。需要动 host 层，等本机可编译验证再做。

## 三、报价模板化（分两步）

- **第一步（本轮）**：① 预置 4 类报价骨架：单条视频 / 细分拆项（前期/拍摄/后期/包装）/ 年框框架 / 月度服务，新建报价选骨架带出行项改数字；② **套用历史报价**：从其他项目档案一键复制行项。
- **第二步（下版）**：自定义模板库（存为模板、命名管理），需动协议与存储，单独立项。

## 四、自动化现状与本轮补齐

- ✅ 资料快照自动带出（已有）：报价/合同/请款/验收单自动带公司信息、银行、条款，输出 Docx/Xlsx。
- ✅ **老客户复用（本轮已完成开发）**：新建商务档案时自动发现同客户历史项目 → 逐字段预览（只填空、不覆盖）→ 一键复用建档。老客户新项目零手填。
- ✅ 界面统一（本轮已完成）：全模块统一新设计语言，导航分组带文字。

## 五、洽谈与审核：已有能力，不重复建设

- **洽谈**：需求访谈模块（结构化问题清单 + Brief 摘要 + 确认锁版）已可用；智能体的"洽谈助手"在它上面做追问和整理，不另起炉灶。
- **审核**：合同审查管线（导入 → OCR → 风险逐条 → 人工决策 → 报告 → 转正式合同）已可用；"合同审核助手"消费它的结果做二次文书。标书拆解后续可复用此管线，单独立项。

## 七、验收口径

- 验收/请款文书：从"翻记录手写"变成"点技能卡 → 得草稿 → 微调 → 带入单据"，单份 3 分钟内。
- 报价：常规报价"选骨架/抄历史 + 改数字"，5 分钟出稿。
- 老客户复用：建档零手填（公司/税号/地址/银行一键带入）。
- 智能体草稿永不直接生效：台账与快照口径与 1.2.2 完全一致。

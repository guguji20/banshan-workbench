# 半山商务工作台 1.2.2 修复说明

- 产品：半山商务工作台
- 版本：`1.2.2`
- 修复日期：`2026-07-26`
- 当前状态：**代码修复完成，等待 Windows 本机 `pnpm verify` + 人工冒烟验收**
- releaseStatus: pending-local-verification

本轮针对「多条业务链路走不通、按钮永久灰死、前后端校验不一致」做了一次系统性修复。共 5 组并行审计（壳层接线 / 单据中心 / 审查与设置 / Rust 服务 / Client SDK），确认缺陷 40+ 项，本版修复其中全部 P0 与绝大多数 P1。

## 一、壳层断链修复（根因）

`BusinessWorkbench`（1.2 新壳）替换 `DesktopShell` 时丢失了约 30 个功能入口，导致整块模块不可达：

- **项目阶段推进**：项目详情面板新增 8 段阶段步进器（接洽→需求→报价→合同→请款→验收→回款→归档），`changeProjectStage` 重新可用；此前"当前环节"永远停在「客户接洽」。
- **拍摄执行单**：新增左侧导航「执行单」，`ExecutionBriefCenter` 重新挂载（新增 `execution` section）。
- **案例库**：新增导航「案例库」，`CaseLibrary` 重新可达；需求访谈的"参考案例"不再永远为空。
- **任务中心**：加入主导航（此前唯一入口藏在项目上下文面板）。
- **系统状态**：新增导航「系统状态」：本地权威、Codex 握手检测按钮、媒体引擎健康、最近事件流。
- **全局错误横幅**：连接失败可见「重试连接 / 关闭」，`retryConnection` 与 `clearError` 首次从 UI 可达。
- 工作台对话列表新增刷新按钮；经营概览点击客户失败时不再静默关闭抽屉（失败保留抽屉并显示原因）。

## 二、商务闭环卡死修复（前后端一致性）

1. **客户签收不再一次性锁死**：后端允许对同一发送批次的**未决版本**继续补签（已决版本不可改写）；批次状态按累计结论收敛。前端签收表单只列出未决版本、至少一项结论才能提交（此前全默认"待确认"提交会静默失败）。
2. **归档预检**：发送批次改为按「是否还有未决版本」判断（全部有结论的批次——包括被拒绝的历史批次——不再永久阻断归档）；前端补齐 `partiallyReceived` 漏检，预检与后端口径一致。
3. **已请款节点可以取消**：先作废对应请款单，再取消付款节点（`Requested→Canceled`）；此前 UI 提供取消按钮但后端必然拒绝，节点永久卡死。前端按钮按新规则联动并给出原因提示。
4. **部分到账节点的请款单可审批**：`ensure_payment_request_target` 与 `create_document` 对齐（允许 `partiallyReceived`），请款单草稿不再"只能作废"。
5. **单据批准不再必然失败**：前端补齐与后端 `ensure_document_approvable` 完全一致的快照校验（合同：服务起止/付款条款/验收条款；请款：收款银行/账号；验收：交付摘要），并且在**创建入口**就提示需要先补全的资料（快照创建时冻结，事后补资料无效——现在会在创建前拦截并说明）。
6. **里程碑必填项**：验收标准标记必填（后端本来就必填，此前静默失败）；已交付/已签收里程碑禁用编辑（系统维护状态，此前保存必失败且状态下拉显示为空）。
7. **税号冲突不再卡死资料保存**：`sync_customer_from_profile` 重写——新税号属于其他客户或当前客户被多工作区共享时，改为**重定向绑定**（并补上此前被绕过的绑定冻结校验）；单工作区独占且税号未被占用时原地更新。
8. **作废生效合同加保护**：存在到账/发票/未作废请款单时禁止作废合同（`BUSINESS_CONTRACT_IN_USE`），杜绝应收变负数、生命周期倒退；财务汇总 `outstandingCents` 增加非负钳制兜底。
9. **红冲金额**：预填改为"剩余可红冲金额"（原为全额）、输入框带上限；红票代码/发票代码标记必填；未选附件时按钮禁用并说明（此前点击完全无反应）。
10. **登记发票**：合同未生效（合同金额为 0）时按钮禁用并说明，不再打开一个必然失败的表单。
11. **闭环服务 CAS 补强**：客户/里程碑更新增加"影响行数=1"校验（`BUSINESS_WORKSPACE_REVISION_CONFLICT`，可重试），并发修改不再静默丢失但仍发成功事件。
12. **取消归档保留审计**：解除归档不再清空 `archivedAt/archivedBy`。
13. **预填只填不清**：源工作区的空字段不再清空目标已有值（税率 0 视为未填写）；预览决策与实际应用保持一致（不再出现"Cleared"实际却保留的错位）。

## 三、界面与数据一致性修复

- 报价确认凭证、到账凭证的「打开/导出」按钮恢复可用（`businessWorkspaceAssetIds` 补齐 receipts 与 quoteConfirmations 的资产收集）。
- 「采用最新已确认需求」「绑定客户」成功后表单即时刷新（草稿按 revision 感知重播种；用户正在编辑的脏草稿不受影响），不再出现"同步没反应、再保存把旧值写回"。
- 合同审查：只生成 JSON 报告时报告卡片与「转为正式合同」入口不再消失；阶段进度条覆盖全部 9 个阶段（等待 OCR/合并风险/生成报告不再显示为零进度）；人工决策备注保存后回显、不再被清空覆盖；智能审查失败提示按"是否已有人工决策"给出准确文案（已决策后按规范不允许重跑）。
- 合同导入失败后清空已选文件（source token 一次性），并提示重新选择；导入相关的未处理 Promise rejection 修复。
- AI 对话「中断」按钮在没有可中断回复时禁用并说明（此前点击无反应）。
- 执行单列表字段可正常换行输入（原来回车被立即吞掉，只能粘贴多行）。
- 案例编辑模式禁用「来源资产」下拉并说明（协议不支持更换，此前改了不生效还提示成功）。
- 需求访谈：误点「未处理」不再清空已写答案；「提交复核」禁用时给出缺失项提示。
- 设置中心：手动检查更新回显 Host 真实结果与最近检查时间；缓存清理条目使用真实位置名称、完成后显示实际释放空间；R2 状态 degraded 判定顺序修正、透出 Host message；飞书渠道 available 状态不再自相矛盾。
- 任务进度显示修复（此前 50% 显示为 5000%）；保存客户/保存里程碑/登记版本三个按钮的 loading 状态恢复（busyAction 键名对齐）。
- 单据类型切换不再丢弃已填标题。
- 后端错误码中文映射补充 20+ 条（单据快照缺失、签收冲突、红冲超额、税号冲突、合同占用等不再显示英文原文）。

## 四、Client SDK 修复

- `clearError()` 现在同时清除已锁存的重放缺口错误（错误横幅的「关闭」不再是死按钮）。
- 快照错误优先级翻转：最新命令失败优先显示，缺口错误作为兜底（不再遮蔽真实失败原因）。
- `start()` 重置全部四路缺口恢复状态（失败重启后陈旧 target 不再抬高恢复窗口）。
- `executeCase` / `executeExecutionBrief` 补齐回执序列缺口自愈（与需求/商务工作区路径对齐）。
- 案例/执行单缺口恢复不再无条件清除全局错误（只清除本流自己的缺口错误）。
- `publish()` 遍历监听器快照，避免通知期间退订跳过监听器；`listBusinessCustomers` 显式 `limit: null` 不再被折叠为 100。

## 六、本机验收步骤（Windows）

```powershell
pnpm install --frozen-lockfile
pnpm verify        # protocol:generate + vitest + tsc + build + cargo fmt/check/clippy/test
pnpm desktop:dev   # 人工冒烟
```

人工冒烟建议路径：
1. 新建项目 → 左侧「执行单」「案例库」「任务中心」「系统状态」四个新入口逐一打开；项目详情面板点阶段芯片推进环节。
2. 资料页缺服务起止/条款时尝试创建合同 → 应在创建入口被拦截并提示补全；补全后走 报价→确认→合同→生效。
3. 请款单生成 → 作废请款单 → 取消该付款节点（应成功）；部分到账后归档预检应显示付款节点未完结。
4. 交付：发送批次 → 只签收部分版本 → 再次签收剩余版本（应成功）→ 全部接受后归档预检通过。
5. 发票登记（未选附件时按钮应禁用）→ 部分红冲（预填应为剩余金额）。
6. 断开 AI 凭据跑合同审查 → 规则降级 → 逐条确认（备注应回显）→ 生成报告（JSON 也应出现卡片）→ 转正式合同。

## 七、界面重构：Frakio 风格导航壳层

参考 [frakio-work](https://github.com/MadsGao/frakio-work) 的布局语言，对 `BusinessWorkbench` 壳层做了一次可用性重构（仅 `BusinessWorkbench.tsx` / `BusinessWorkbench.css` 两个文件）：

- **带文字的分组导航**：左侧 46px 纯图标栏改为 206px 分组导航——「业务主线」（工作台/需求访谈/报价 · 单据/合同审查）、「交付执行」（执行单/任务中心/案例库）、「资料状态」（商务归档/系统状态），完全按业务闭环顺序排列；不再需要悬停猜图标。
- **可折叠**：底部新增「精简导航」（折回 54px 图标栏）与「隐藏列表」（隐藏第二列列表栏）两个开关；列宽走 CSS 变量 + `cubic-bezier(.2,.8,.2,1)` 360ms 过渡，窄窗口自动降级（<1320px 自动精简导航，<1060px 上下文改浮层，<780px 移动布局）。
- **柔和配色**：整体换为暖灰绿底（`#f7f8f6` 画布 / `#f1f3ee` 列表栏 / `#edf0ea` 导航栏）+ 墨绿主色 `#0f766e`；选中项为白色圆角块 + 左侧主色条。顶栏加高到 54px，显示「页面标题 + 一句话说明」。
- 使用 `--bw-*` 变量的模块（合同审查、AI 工作台、任务中心、资产库）自动跟随新配色；`prefers-reduced-motion` 下关闭动画。

# 半山商务工作台 1.2.3 更新说明

- 版本：`1.2.3`
- 日期：`2026-07-26`
- 主题：**商务提效三件套 + 全站界面统一**（对应《商务板块方案 V3》本轮范围）
- 本轮改动 **全部为前端**（TypeScript/CSS），未改任何 Rust 代码；`cargo` 相关风险与 1.2.2 一致，本机验收流程不变
- releaseStatus: pending-local-verification

设计原则（按最新要求执行）：尽量简洁、不重复造轮子、入口要少、文案说人话。三个新功能都没有新增导航入口——分别长在建档页、资料页、对话框上方。

## 一、商务智能体（工作台 · 对话框上方）

类 frakio 的多角色 AI 助手，专治重复文书。四个角色，每个带 3 张一键技能卡：

- **洽谈助手**：生成追问清单 / 聊天记录整理成 Brief / 模糊反馈追问话术
- **报价助手**：按需求起草报价行项 / 行项说明润色 / 报价说明函
- **合同审核助手**：合同修改意见函 / 汇总审查纪要 / 大白话解释条款
- **验收请款助手**：验收单交付摘要 / 请款说明 / 回款催收话术

点技能卡 → 自动把"要说的话 + 当前项目的真实资料"（合同金额、付款节点、里程碑、审查发现、需求 Brief）写进输入框 → 看一眼就能发送。生成内容永远只是草稿，正式生效必须回单据流程；提示词里写死了"金额日期以资料为准，缺什么标【待补充】，不许编数"。

## 二、老客户资料复用（报价/单据 · 新建档案时）

项目还没有商务档案时，建档页会自动查找同客户的历史项目：

- 列出候选（项目名、客户、匹配方式、可带入的资料项数、最近更新时间）
- 点开逐字段预览：哪些「带入」、哪些「保持」，税率等自动转成百分比显示
- 一键「复用并建立商务档案」；规则是**只填空缺项、绝不覆盖**已有值
- 也可以照旧「建立空白商务档案」

后端能力 1.2.2 已就绪，本轮补上了界面入口。老客户新项目从此不用重填公司/税号/地址/银行。

## 三、报价模板（报价/单据 · 客户页 · 服务明细）

- **套用报价模板**：内置 4 套常用结构——单条视频（4 项）、细分拆项（10 项）、年框/框架服务（4 项）、月度服务（4 项）。模板不带价格，套用后改数字即可。
- **套用历史报价**：其他项目的服务明细一键复制过来（带原价）。只在存在其他有明细的项目时出现。
- 两者都是追加进列表，空白行自动清掉，随时可改可删。
- 「存为我的模板」需要动协议与存储，按方案排在 1.3。

## 四、全站界面统一（延续 1.2.2 的新壳层）

## 六、本机验收补充路径（在 1.2.2 验收基础上增加）

1. 工作台 → 点「验收请款助手」→ 点「起草请款说明」→ 输入框应出现带真实合同金额/付款节点的请求文本 → 发送看生成效果。
2. 选一个没有商务档案的项目 → 报价/单据 → 应看到「老客户资料复用」候选（若有同客户历史项目）→ 预览 → 复用建档 → 资料页字段应已带入。
3. 资料页 → 服务明细 → 「套用报价模板…」选「细分拆项」→ 应追加 10 行空价行项；如有其他项目，「套用历史报价…」应带原价复制。

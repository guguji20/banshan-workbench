# 商务全链路一致性字段

| 字段组 | 关键字段 | 主要比较链路 |
|---|---|---|
| 主体 | 客户法定名称、我方主体、联系人 | Brief↔合同↔主档↔请款 |
| 项目 | 项目名称、项目编号、服务类型 | 全链路 |
| 范围 | 服务项、数量、单位、规格、排除项 | Brief↔报价↔合同↔验收 |
| 价税 | 币种、未税、税率、税额、含税总额 | 报价↔合同↔主档↔请款 |
| 付款 | 节点、比例、金额、触发条件、账期 | 合同↔主档↔请款 |
| 交付 | 交付物、日期、形式、版本 | Brief↔合同↔主档↔验收 |
| 验收 | 标准、期限、整改、签章 | 合同↔主档↔验收 |
| 权利 | 版权、源文件、素材授权、案例展示 | Brief↔合同↔主档 |
| 版本 | Artifact revision、合同版本、交付版本 | 全链路 |

比较结果只允许：一致、允许差异、冲突、缺失、无法判断。每个结果必须带来源版本和定位。

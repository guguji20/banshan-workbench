# 标书提交最小清单

| 类别 | 必查项 | 输出状态 |
|---|---|---|
| 时间 | 截止时间、答疑时间、有效期 | 已确认/待确认 |
| 提交 | 线上/线下、地址、文件命名、加密、份数 | 已确认/待确认 |
| 资格 | 主体资格、行业资质、信用、业绩 | 已具备/缺失/待核 |
| 授权 | 法人证明、授权书、身份证明 | 已具备/缺失/待核 |
| 报价 | 模板、税率、大小写、分项、限价 | 一致/冲突/待核 |
| 签章 | 签字、盖章、骑缝章、电子章 | 完成/未完成/待核 |
| 装订 | 目录、页码、密封、正副本 | 完成/未完成/待核 |
| 否决项 | 星号条款、废标条件、保证金 | 通过/阻断/待核 |

所有“完成/通过”必须有人工确认或可靠记录。

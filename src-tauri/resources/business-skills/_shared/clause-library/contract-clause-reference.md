# 合同条款参考

本文件只定义审查关注点，不是法律模板，不得直接作为最终条款。

| 条款 | 关注字段 | 常见风险信号 |
|---|---|---|
| 服务范围 | 交付物、数量、规格、排除项 | “按甲方要求”但无边界 |
| 变更 | 提交、确认、费用、排期 | 口头变更自动生效 |
| 付款 | 节点、条件、账期、发票 | 付款依赖无限期内部流程 |
| 验收 | 标准、期限、反馈、整改 | 无标准或无限次修改 |
| 知识产权 | 成果、源文件、第三方素材 | 全部权利转让但范围不明 |
| 案例展示 | 可公开内容、时间、渠道 | 默认禁止且无例外 |
| 违约责任 | 违约金、赔偿范围、上限 | 单方无限责任 |
| 解除退款 | 解除条件、已完成工作结算 | 任意解除并要求全额退款 |
| 保密数据 | 范围、期限、例外、删除 | 义务无限且无合理例外 |
| 争议解决 | 法律、法院/仲裁地 | 异地高成本管辖 |

建议文本必须引用实际合同事实，并标注“待授权人员确认”。
